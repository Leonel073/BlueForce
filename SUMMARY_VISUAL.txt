┌────────────────────────────────────────────────────────────────────────────────┐
│ 🔐 SEGURIDAD IMPLEMENTADA                                                      │
└────────────────────────────────────────────────────────────────────────────────┘

   Principio: Un usuario solo puede operar documentos bajo su responsabilidad

   Métodos Protegidos:

   ✅ derivar()      → Verifica responsable actual
   ✅ finalizar()    → Solo admin en correspondencia admin
   ✅ recibir()      → Verifica responsable actual
   ✅ atender()      → Verifica responsable actual
   ✅ archivar()     → Verifica responsable actual
   ✅ finalizar()    → Verifica responsable actual

   Escenarios Bloqueados:

   ❌ User A derivar documento ya derivado
   ❌ User A finalizar documento de User B
   ❌ User C recibir documento de User B
   ❌ Usuario normal acceder módulo admin
   ❌ Admin bloqueado (permitido realizar todo)
