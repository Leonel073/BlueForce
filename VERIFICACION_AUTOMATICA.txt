PROBLEMAS IDENTIFICADOS
═══════════════════════════════════════════════════════════════════════════════

❌ PROBLEMA 1: MI BANDEJA (envios.bandeja)
   - Admin y User ven MISMA vista: envio.bandeja
   - Admin debería ver: admin.envios.bandeja.blade.php (existe ✅)
   - EnvioController::bandeja() retorna: view('envio.bandeja') para AMBOS
   - NO DETECTA ROL

❌ PROBLEMA 2: REDIRECCIÓN POST-REGISTRO (DocumentoController::store())
   - Línea ~430 en DocumentoController.php
   - Retorna: redirect()->route('admin.correspondencia')
   - PROBLEMA: User intenta redirigir a ruta ADMIN
   - Usuario recibe error 403 (no tiene permiso)
   - Debería ser: dinamico según rol

⚠ PROBLEMA 3: DocumentoController::index()
   - Retorna: view('correspondencia.index')
   - Este también es llamado por user (sin admin prefix)
   - Pero retorna MISMA VISTA para admin y user
   - Debería retornar vista diferente según rol (como CorrespondenciaController hace)

⚠ PROBLEMA 4: Posible ruta duplicada en ADMIN documentos
   - Usuario normal accede a: /documentos (user middleware)
   - Admin accede a: /admin/documentos (admin middleware)
   - Pero index() en DocumentoController retorna misma vista para ambos
