📊 TABLA AUDITORIA - ESTRUCTURA
═══════════════════════════════════════════════════════════════════════════════

Campos principales:
  • idAuditoria (PK)
  • idUsuario (FK usuarios)
  • modelo (nombre del modelo)
  • idRegistro (ID del registro afectado)
  • accion (ENUM: CREATE, UPDATE, DELETE)
  • datosAnteriores (JSON - datos antes del cambio)
  • datosNuevos (JSON - datos después del cambio)
  • ip (IPv4 o IPv6 del cliente)
  • navegador (User Agent)
  • ruta (URL accedida)
  • fecha (timestamp del evento)
  • created_at, updated_at (timestamps)

Índices:
  • idx_idUsuario
  • idx_modelo
  • idx_accion
  • idx_fecha
  • idx_modelo_idRegistro
  • idx_idUsuario_fecha
  • idx_accion_fecha

🔄 FLUJO DE AUDITORÍA AUTOMÁTICA
═══════════════════════════════════════════════════════════════════════════════

Usuario realiza acción
    ↓
Laravel detecta evento (created, updated, deleted)
    ↓
GenericAuditObserver intercepta
    ↓
Captura información:
    - Usuario autenticado
    - Datos antes/después (UPDATE)
    - IP del cliente
    - Navegador/User Agent
    - URL accedida
    - Timestamp exacto
    ↓
Filtra campos sensibles (password, token, etc)
    ↓
Inserta en tabla AUDITORIA
    ↓
Disponible en dashboard instantáneamente
    ↓
Puede ser consultado, filtrado, exportado
