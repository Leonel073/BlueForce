┌─────────────────────────────────────────────────────────────────────────┐
│ CORRECCIÓN #2: CITE → CÓDIGO DE RUTA (AUTOMÁTICO)                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│ ❌ ANTES (Manual):                                                     │
│    • Campo CITE: input text requerido                                 │
│    • Usuario ingresa manualmente (ej: SGPA-2026-05-001)              │
│    • Sin formato consistente                                          │
│    • Riesgo: errores de tipeo                                         │
│                                                                       │
│ ✅ DESPUÉS (Automático):                                              │
│    • Campo "Código de Ruta": input readonly (no editable)            │
│    • Se genera automáticamente al cambiar Tipo o Urgencia           │
│    • Formato: [LetraTipo][LetraUrgencia]-AAAA-MM-DD-[#]            │
│    • Usuario VE el código pero NO puede modificarlo                 │
│                                                                       │
│ 🔧 LÓGICA DE GENERACIÓN:                                             │
│                                                                       │
│    Tipo Documento  +  Nivel Urgencia  +  Fecha     →  Código        │
│    ─────────────────────────────────────────────────────────────    │
│    Memorándum (M)      Normal (N)       2026-05-05    MN-2026-05-05-1 │
│    Carta (C)           Urgente (U)      2026-05-05    CU-2026-05-05-1 │
│    Resolución (R)      Muy Urgente (M)  2026-05-05    RM-2026-05-05-1 │
│                                                                       │
│ 📝 EJEMPLOS REALES:                                                  │
│    • Memorándum Normal      → MN-2026-05-05-1                       │
│    • Carta Urgente         → CU-2026-05-05-1                        │
│    • Resolución Muy Urgente → RM-2026-05-05-1                       │
│                                                                       │
│ 📝 BENEFICIO:                                                        │
│    • Sin errores de tipeo                                            │
│    • Formato consistente en toda la institución                      │
│    • Fácil de rastrear y categorizar                                │
│    • Usuario ve exactamente cómo se guardará                        │
│    • Futuro: número secuencial dinámico desde BD                    │
│                                                                       │

   • Sistema crea:
     ├─ 1 PERSONA (remitente)
     ├─ 1 CORRESPONDENCIA (documento)
